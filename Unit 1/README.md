🧠 OOP Concepts Demonstrated

🏛️ Class

A class defines the structure and behavior of objects.

👤 Object

An object is an instance of a class containing its own state and behavior.

🔐 Encapsulation

Combines data and functions within a class and controls access to the data.

🎭 Abstraction

Provides essential functionality while hiding unnecessary implementation details.

⚙️ Functions

Reusable blocks of code used to perform specific operations.

📝 Function Prototype

Declares a function before its actual definition.

🏗️ Constructor

Automatically initializes an object when it is created.

🗑️ Destructor

Automatically executes when an object is destroyed.

🔢 Static Data Member

A class-level data member shared by all objects of the class.

⚡ Static Member Function

A member function that operates on static class-level data.

🚀 Inline Function

A function that can be expanded at the point of invocation to reduce function-call overhead where appropriate.

🤝 Friend Function

A non-member function that can be granted access to private and protected members of a class.

🔀 Control Structures

Used to control program execution using conditions and loops.

🔢 Arrays

Used to store multiple values of the same type.

🔤 Strings

Used to represent and manipulate textual data.
