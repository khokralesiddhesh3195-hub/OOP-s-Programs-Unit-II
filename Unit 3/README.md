🧠 <b>Polymorphism Concepts Demonstrated</b>

🔄 <b>Polymorphism</b>

Polymorphism allows the same interface or operation to behave differently depending on the context or object.

⚙️ <b>Function Overloading</b>

Multiple functions can have the same name with different parameter lists.

➕ <b>Operator Overloading</b>

Operators can be given meaningful behavior for user-defined classes.

🔢 <b>Unary Operator Overloading</b>

Overloads operators that work with one operand, such as unary "-" and "++".

➕ <b>Binary Operator Overloading</b>

Overloads operators that work with two operands, such as "+", "-", "*", and relational operators.

⏱️ <b>Compile-Time Polymorphism</b>

Function overloading and operator overloading are examples of compile-time polymorphism.

🔁 <b>Run-Time Polymorphism</b>

Run-time polymorphism allows the appropriate overridden function to be selected during program execution.

🔷 <b>Virtual Function</b>

A virtual function enables dynamic binding when accessed through a base-class pointer or reference.

🧩 <b>Pure Virtual Function</b>

A pure virtual function is declared using "= 0" and requires derived classes to provide an implementation.

🏛️ <b>Abstract Base Class</b>

A class containing at least one pure virtual function is abstract and cannot be instantiated directly.

👉 <b>Base-Class Pointer</b>

A base-class pointer can refer to a derived-class object and enable runtime polymorphism when virtual functions are used.

🔗 <b>Base-Class Reference</b>

A base-class reference can refer to a derived object and provide runtime polymorphic behavior.

🗑️ <b>Virtual Destructor</b>

A virtual destructor ensures proper destruction of derived objects through base-class pointers.

✂️ <b>Object Slicing</b>

Object slicing occurs when a derived-class object is copied into a base-class object by value, causing the derived-specific portion to be lost.
